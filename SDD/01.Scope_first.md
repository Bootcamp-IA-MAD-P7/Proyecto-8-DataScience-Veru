- Objetivo del proyecto: 
Elaborar un prototipo de programa con inteligencia artificial que de manera desatendida y como criba previa a una consulta con doctor pida por línea de comandos los datos necesarios y devuelva si el paciente está en riesgo de sufrir un ictus. Para validar el proyecto, será necesario también un informe de su rendimiento.

Arquitectura inicial:
Se utilizará uv para orquestar las dependencias y evitar conflictos en el entorno virtual y llevar a cabo un adecuado control de versiones. 

> uv add  

De forma inicial, se plantea la instalación de las siguientes  dependencias: pandas, matplotlib, seaborn, fastapi, skeat-it learn, pytest y jupytext como punto de inicio.

Se crea un makefile que orquestará las principales funciones automatizadas del proyecto: la creación de notebooks, train para entrenar los modelos, smote para balancearlos, test para realizarlos de forma conjunta, así como el despliegue en docker. 

Se crean las carpetas base frontend y backend, src, data (con dataset incorporado), y carpetas/eda.py listas para comenzar el EDA.
